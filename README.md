# Компьютерная графика

Репозиторий содержит проекты, связанные с обработкой и визуализацией изображений:

## Проекты

### [ImageProcessing](./WinFormsApp1/README.md)

Редактор изображений с широким набором фильтров:
- Точечные фильтры (инверсия, оттенки серого, сепия, яркость и др.)
- Матричные фильтры (размытие, Гауссово размытие, Motion Blur, тиснение и др.)
- Морфологические операции (расширение, сужение)

Используемые технологии:
- .NET 8.0
- Windows Forms


### [TomogramVisualizer](./TomogramVisualizer/README.md)

Приложение для визуализации томограмм (файлов формата .bin) с возможностью просмотра послойных срезов трехмерного изображения. Проект реализует несколько режимов отображения: квадратами, текстурами и QuadStrip.

Используемые технологии:
- .NET Framework 4.8
- OpenTK для работы с OpenGL
- Windows Forms


### [RayTracing](./RayTracing/README.md)

Реализация трассировщика лучей для создания реалистичных изображений трехмерных сцен. Поддерживает отражение, преломление, тени и модель освещения Фонга.

Используемые технологии:
- .NET 8.0
- OpenTK (OpenGL 4.3 Core)
- GLSL шейдеры
- Windows Forms
