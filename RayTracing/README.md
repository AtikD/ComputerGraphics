# RayTracing

## Описание

RayTracing - это приложение для создания фотореалистичных изображений с использованием алгоритма трассировки лучей (Ray Tracing). Проект демонстрирует реализацию основных эффектов физически корректного освещения, отражений и преломлений в реальном времени.

## Функциональность

- Рендеринг 3D сцены методом трассировки лучей
- Поддержка различных типов материалов:
  - Диффузные материалы
  - Отражающие поверхности
  - Преломляющие материалы
- Физически корректная модель освещения Фонга
- Обработка теней от объектов
- Интерактивное управление камерой
- Отображение FPS для контроля производительности

## Архитектура

### Основные компоненты

1. **Form1** - главная форма приложения с OpenGL контролем
   - Обрабатывает основной цикл отрисовки
   - Управляет камерой и интерактивностью

2. **View** - класс для управления графическим выводом
   - Инициализация шейдеров и буферов
   - Управление камерой (позиция, направление)
   - Отрисовка сцены

3. **debug** - вспомогательная форма для настройки камеры
   - Позволяет вручную устанавливать позицию и направление камеры
   - Открывается по нажатию клавиши 'Q'

4. **Шейдеры**:
   - `raytracing.vert` - вершинный шейдер
   - `raytracing.frag` - фрагментный шейдер с реализацией алгоритма

## Особенности реализации

### Сцена

Сцена содержит:
- Сферы (2 шт) с различными материалами
- Треугольники (10 шт), образующие стены комнаты
- Один источник освещения

### Материалы

Проект поддерживает три типа материалов:
1. **DIFFUSE** - матовые поверхности
2. **REFLECTION** - зеркальные поверхности
3. **REFRACTION** - преломляющие материалы

Каждый материал имеет параметры:
- Цвет
- Коэффициенты освещения (ambient, diffuse, specular)
- Коэффициент отражения
- Коэффициент преломления

### Алгоритм трассировки

- Использует стек для обработки отраженных и преломленных лучей
- Поддержка рекурсивной трассировки с ограничением глубины
- Оптимизирован для работы в реальном времени

## Технические детали

- Разработано на платформе .NET 8.0
- Использует OpenTK для работы с OpenGL
- Графический интерфейс реализован с помощью Windows Forms
- Шейдеры написаны на GLSL версии 430 core

## Управление

- **Q** - открыть окно настройки камеры
- В окне отладки можно вручную установить:
  - Позицию камеры (X, Y, Z)
  - Направление камеры (X, Y, Z)

## Особенности визуализации

Приложение отображает:
- Счетчик FPS в заголовке окна
- Интерактивную 3D сцену с реалистичным освещением
- Отражения между объектами
- Тени и другие эффекты

Проект демонстрирует мощь современных шейдеров и возможность создания фотореалистичной графики в реальном времени.
