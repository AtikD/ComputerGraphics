# TomogramVisualizer

## Описание

TomogramVisualizer - это приложение для визуализации томографических данных, хранящихся в бинарных файлах формата .bin. Программа позволяет загружать трехмерные томограммы и просматривать их по слоям, обеспечивая наглядное представление внутренней структуры объектов.

## Функциональность

- Загрузка бинарных файлов томограмм
- Визуализация томограмм послойно с использованием OpenGL
- Три режима отображения:
  - Квадратами (покоординатная отрисовка)
  - Текстурами (используя текстуры OpenGL)
  - QuadStrip (оптимизированный режим отрисовки)
- Выбор слоя для просмотра с помощью ползунка
- Отображение счётчика FPS для оценки производительности

## Архитектура

### Основные компоненты

1. **Bin** - класс для чтения бинарных данных томограммы
   - Загружает 3D массив данных из файла
   - Хранит информацию о размерности томограммы (X, Y, Z)

2. **View** - класс для визуализации данных с использованием OpenGL
   - Содержит методы отрисовки разными способами
   - Выполняет передачу данных в графическую подсистему
   - Реализует функцию передачи для визуализации (transfer function)

3. **Form1** - основная форма приложения
   - Предоставляет пользовательский интерфейс
   - Управляет загрузкой и отображением данных
   - Обеспечивает переключение между режимами отрисовки

## Технические детали

- Разработано на платформе .NET Framework 4.8
- Графический интерфейс реализован с использованием Windows Forms
- Визуализация выполняется с помощью OpenTK (обёртка OpenGL для .NET)
- Формат входных данных:
  - Бинарный файл (.bin)
  - Структура: 3 целых числа (размерности X, Y, Z), затем массив значений (16-бит)

## Использование

1. Запустите приложение
2. Выберите "Файл" -> "Открыть" и укажите путь к файлу томограммы (.bin)
3. Используйте ползунок внизу окна для переключения между слоями
4. Выберите режим отрисовки в меню "Отрисовка"
