# Редактор изображений

## Описание

Редактор изображений представляет собой Windows-приложение для обработки растровых изображений с использованием различных фильтров и эффектов. Программа обеспечивает широкий спектр возможностей для манипуляции изображениями и визуализации результатов в режиме реального времени.

## Функциональность

### Точечные фильтры

Фильтры, которые преобразуют каждый пиксель изображения независимо:

- **Инверсия** - инвертирует цвета изображения
- **Оттенки серого** - преобразует изображение в градации серого
- **Сепия** - придаёт изображению тёплый коричневатый оттенок
- **Яркость** - регулировка яркости с помощью ползунка
- **Сдвиг** - смещение изображения по осям
- **Серый мир** - цветовая коррекция с применением алгоритма "Серый мир"
- **Линейное растяжение** - растягивает гистограмму для улучшения контраста
- **Идеальный отражатель** - нормализует цветовые каналы

### Матричные фильтры

Фильтры, использующие информацию о соседних пикселях:

- **Размытие** - равномерное размытие
- **Gaussian** - размытие по Гауссу
- **Motion Blur** - эффект движения
- **Тиснение** - создаёт эффект рельефности
- **Собеля** - выделение границ
- **Щарра** - альтернативный метод выделения границ

### Морфологические операции

- **Расширение** - морфологическое расширение, увеличивает яркие области
- **Сужение** - морфологическое сужение, уменьшает яркие области
- **Медиана** - медианная фильтрация для удаления шума

## Архитектура

Проект использует объектно-ориентированный подход с базовым абстрактным классом Filters, от которого наследуются все специфические фильтры. Это обеспечивает удобное расширение функциональности и добавление новых фильтров.

### Основные компоненты

1. **Form1** - основная форма приложения, содержащая пользовательский интерфейс
2. **Filters** - абстрактный базовый класс для всех фильтров
   - Точечные фильтры (InvertFilter, GrayScaleFilter, и т.д.)
   - Матричные фильтры (MatrixFilter и его производные)
   - Морфологические фильтры (DilationFilter, ErosionFilter, и т.д.)
3. **Form2** и **ShiftForm** - диалоговые окна для настройки параметров фильтров

## Технические детали

- Разработано на платформе .NET 8.0
- Графический интерфейс реализован с использованием Windows Forms
- Обработка изображений выполняется асинхронно с отображением прогресса
- Возможность отмены операции во время выполнения

## Использование

1. Запустите приложение
2. Выберите "Файл" -> "Открыть" для загрузки изображения
3. Выберите нужный фильтр из меню "Фильтры"
4. Для фильтров с настраиваемыми параметрами установите значения в появляющемся диалоговом окне
5. Наблюдайте прогресс обработки и получите результат
